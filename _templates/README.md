# Writing a new post

1. Copy `post.md` into `_posts/`.
2. Rename it to `YYYY-MM-DD-short-title.md`.
3. Replace every front-matter placeholder.
4. Keep the publication time earlier than the build time so Jekyll lists it.
5. Write headings in order: `##` for sections and `###` for subsections.
6. Add a short excerpt that works on the homepage and in social previews.
7. Check links and code examples before publishing.

The `_templates` directory is excluded from the generated site.
